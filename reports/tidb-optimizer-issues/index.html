1. 筛除噪声与高价值保留边界

  • Random / 差分 Fuzz（122 条）：包含 fuzz/sqlancer、fuzz/randomtest、fuzz/shiro 以及 TLP/NoREC/CERT 多层 NATURAL JOIN + 跨类型 BIT/BLOB/ZEROFILL 集合运算、Prepared 随机内建函数对拍与 opt_rule_blacklist 强关规则用例。
  • AI 静态猎奇边界（25 条）：刻意构造 Expression.HashCode() 碰撞（如 #70982、#70645）、slow_query 1970 纪元零值或超 2262 年哨兵（#72669、#72662）及未默认开启开关的静态审计。
  • 虽由 AI/测试发现但予以保留的高危真 Bug：部分索引共享 Range 切片篡改选错路径（#69779）、Plan Cache 遗漏会话变量（#69650）、ANALYZE 与 ADD COLUMN 死锁（#72861）、ENUM 混合条件误判 TableDual（#72098）、多列 IN 漏去重（#71928）。

2. 实为 Enhancement 的专项标注（59 条）

  • 谓词化简与短路求值：矛盾不等式折叠 TableDual（#69058）、跨 INTERSECT/CTE 空集传播（#72223）、二进制列跨排序规则常量传播（#71776）、含子查询的 TRUE OR ... 短路（#63573）。
  • 聚合/连接等价改写：外键聚合下推（#63806）、DISTINCT 转 SemiJoin / Loose Index Scan（#69932、#18693）。
  • 排序属性与 DML 访问路径：关联等值列作为索引常量前缀消 TopN（#69156）、FD 裁剪主键后冗余 ORDER BY（#72585）、DELETE 支持 Batch_Point_Get（#63356）、向量 HNSW ef_search 调节（#72174）。

3. Easy（47 条）& Medium（144 条）核心分布

  • 🟢 Easy（1~3 天）：权限漏检（#62429、#62159、#57429）、getTotalRowCount 遍历 map 非确定性（#72503）、唯一键/桶上界局部估算修正（#72873、#72804）、memtable 正则/时间提取与 Hint 警告补齐（memtable_infoschema_extractor.go）。
  • 🟡 Medium（3~7 天）：firstrow() 谓词下推越界（#71738）、穿透投影重排重算 RAND()（#72032）、分区表 FOR UPDATE OF 漏锁（#72025）、RENAME TABLE 与 Instance Plan Cache 串表/panic（#71041、#72785）、Global Stats 多值索引/JSON TopN 合并缺陷（global_stats.go）。

4. Hard（85 条，1~3+ 周）四大深水区

  • CBO 代价与 Out-of-Range 外推：关联 Apply 扇出低估击败 MPP（#69092、#69392）、时间递增列超界估算失真（#67093、#65924、#64820）及 TiKV/TiFlash 跨引擎代价抖动（selectivity.go）。
  • ANALYZE OOM / GC 阻塞 / 系统表死锁：采样内存失控（#70523、#61450）、阻塞集群 GC 12h+（#63157）、stats_meta 死锁与缓存竞态（#72869、#70964）。
  • MPP 隔离与名称解析历史债：enforce_mpp 误路由悲观锁点查（#67485）、重复表达式索引随机绑定隐藏列（#70708）及 planbuilder.go 单遍名称解析与 ONLY_FULL_GROUP_BY 积压单。
